# Mistral Le Chat Is Now Vibe: Europe's Serious Answer to ChatGPT

Start with the name, because searching for the wrong one wastes time. **Le Chat has been renamed Vibe.** Accounts, subscriptions, conversations, and saved content carried over, and chat.mistral.ai remains the entry point. Documentation paths that used to sit under `/le-chat/` now redirect to `/vibe/`. If you are looking for Le Chat, you have found it; it just answers to something else now.

What sits behind the rename is the most credible non-American alternative in this category: a French company with its own frontier models, genuine data residency in Europe, and openly licensed weights you can run yourself.

## What is Mistral Le Chat (Vibe)?

Vibe is Mistral AI's assistant, combining general chat, workplace tooling, and a coding agent in one subscription. It runs on Mistral's own model stack, including **Mistral Medium 3.5** as a frontier-class multimodal model for agentic and coding work, plus dedicated reasoning, coding, voice, and document models.

The product splits into three modes. **Chat** is the general assistant, with Deep Research, a Think mode for harder reasoning, a code interpreter, Memories, and Agents. **Work** connects to Google Workspace, Outlook, and Slack, and adds Skills, Workflows, Libraries, and scheduled tasks. **Code** provides a CLI, a VS Code extension, and cloud sandbox sessions that can run through to opening a pull request.

Mistral is independent and European. It raised €1.7 billion in September 2025 led by ASML, which took roughly 11% and became its largest shareholder at a €11.7 billion post-money valuation, followed by $830 million in debt financing in March 2026 for a 44MW data centre. CEO Arthur Mensch has said Mistral should pass €1 billion in revenue in 2026.

## Key Features

- **Three modes in one subscription** — general chat, workplace assistant with connectors, and a full coding agent, without separate purchases.
- **Deep Research** — multi-source research reports, comparable in intent to what OpenAI and Google offer.
- **Coding from terminal to pull request** — the Vibe CLI and VS Code extension work on real repositories, with cloud sandbox sessions.
- **Workplace connectors** — Google Workspace, Outlook, and Slack, so answers draw on your actual work context.
- **Skills and Workflows** — encode repeated processes once and run them on demand or on a schedule.
- **European data residency** — Paris-hosted infrastructure and a no-telemetry mode, which is the decisive factor for many EU organisations.
- **Openly licensed models** — many Mistral weights are Apache 2.0, making self-hosting and air-gapped deployment genuinely possible.
- **Memories** — retains context across conversations rather than starting cold each time.

## Pros and Cons

**Why it is worth a look**

Price is the immediate draw: Pro at $14.99/month undercuts the $20 standard, and a verified-student rate of $5.99/month is among the cheapest serious options available. Bundling a capable coding agent into that price is unusual value.

The deeper argument is sovereignty and control. For European organisations with GDPR obligations or public-sector procurement rules, Paris-hosted data and a no-telemetry mode answer questions that no American vendor can. The Apache 2.0 licensing on many models goes further — if you need to run a model inside your own infrastructure with no external calls at all, that path exists. Very few competitors offer it.

**Where it falls short**

The ecosystem is smaller. Fewer integrations, fewer tutorials, fewer third-party tools, and a smaller community mean you will more often be solving problems yourself rather than finding an existing answer. Mistral does not publish exact per-tier usage limits, and the free tier is reported to be soft-capped around 25 messages per day on the better models, which makes it more of a trial than a usable free plan.

Coverage also disagrees on whether image generation and voice are currently present in the consumer product, so if either matters to you, verify in the live app before subscribing. Some users have reported being upsold on image editing and then hitting image limits mid-conversation. And the recent rename means much of the writing about this product, including its own older documentation links, refers to a name the product no longer uses — expect some friction when searching for help.

Reported pricing runs: Free $0, Pro $14.99/month, Education $5.99/month for verified students, Team $24.99/user/month or $19.99 annually, and custom Enterprise, with annual billing discounted 20%. Note that a Vibe subscription does not include API access; La Plateforme is billed separately from around $0.10 per million tokens with a rate-limited free tier for experimentation.

## How to Use Mistral Le Chat (Vibe)

1. **Go to chat.mistral.ai** and sign up free, or install the iOS or Android app. Existing Le Chat logins still work.
2. **Pick your mode first.** Chat for general questions, Work when you need your documents and email in scope, Code when you are working in a repository.
3. **Connect your workspace** if you are evaluating it for work — the connectors are where Vibe stops being generic and starts being useful.
4. **Turn on Think mode for hard problems** and leave it off for drafting, where speed matters more than depth.
5. **Install the CLI or VS Code extension** if you write code. This is the part of the product most likely to change your mind about it.
6. **Enable no-telemetry mode** if data handling is a concern, and check the data residency documentation before putting real business content in.
7. **Build Skills for recurring work,** and schedule Workflows for anything you currently do manually every week.

### FAQs

**Is Le Chat the same as Vibe?**
Yes. Mistral renamed Le Chat to Vibe, unifying the assistant and its coding agent under one name. Accounts, plans, conversations, and saved content transferred automatically, and chat.mistral.ai still works. Older documentation URLs redirect to the new paths. If an article refers to Le Chat, it is describing this product under its previous name.

**How much does Mistral's assistant cost?**
Reported tiers are Free at $0, Pro at $14.99/month, an Education rate of $5.99/month for verified students, Team at $24.99 per user monthly or $19.99 annually, and custom Enterprise pricing, with 20% off annual billing. API usage through La Plateforme is billed separately and is not included in a subscription. Confirm current figures on Mistral's pricing page.

**Is Mistral good enough to replace ChatGPT?**
For general writing, analysis, and coding, it is competitive, and its coding tooling is a real strength at the price. What you give up is ecosystem breadth — integrations, community resources, and consumer extras. If data residency in Europe or the ability to self-host matters to you, Mistral is arguably the better choice outright; if you want maximum features and tooling, ChatGPT still leads.

**Can I run Mistral's models on my own hardware?**
Many are released under Apache 2.0, so yes — self-hosting and air-gapped deployment are supported use cases, which distinguishes Mistral from every major US competitor. Not every model is openly licensed, so check the licence for the specific model you intend to deploy.
